Problem 0.12 Tension: Playing with an Elastic String with Bead.

  1. Attach one end of the elastic white string to the wooden bead. Take the string with bead and hang it straight down with the bead at the bottom. Wait for it to stop moving. Note the length of the string (you don’t have to measure it). Question: How does the tension in the string at this moment compare to the weight \(mg\) of the bead? Is \(T \lt mg\text{,}\) does \(T =mg\text{,}\) or is \(T> mg\text{?}\) Now, add the weight of the round metal spring to the bead. (One way to do this: put the bead inside in the middle of the spring and thread the string out between the coils.) Let the system hang motionless (hold the string with the bead and spring at the bottom pulling downward). Comment on the length of the elastic string now. What is the tension in the string now (answer qualitatively — no numbers)?
    🔗
    🔗
  2. Qualitatively, what happens to the length of the string when the tension increases? What happens to the length of the string when the tension decreases? What do you think will happen to the string if the tension goes to zero?
    🔗
    🔗
  3. Now let the weight and bead hang straight down. Once the system is motionless, pull the top of the string upward, accelerating the system momentarily. What happens to the string’s length? What does this mean about the tension in the string when the bead is accelerated upward? Do the same thing, but this time accelerate the bead/weight downward (quickly lower your hand holding the top of the string). What happens to the tension in the elastic string when the bead accelerates downward?
    🔗
    🔗
  4. Now, take the yo-yo and hang it straight down from its string. Accelerate the yo-yo upward and watch what happens. Accelerate the yo-yo downward and watch what happens. Do you observe any changes in the string in either case? What do you think is happening to the tension in the string in both cases? Note that if you accelerate the yo-yo downward hard enough, the string buckles. What does this mean about the tension in the string for a large downward acceleration?
    🔗
    🔗
  5. A very common misconception is that tension for a hanging object is always equivalent to its weight \(mg\text{.}\) This is not true if the object is accelerating!! If this exercise hasn’t made that point clear, talk with your problem session instructor. Under what circumstances is the tension in the string equal to its weight?
