    Section 9.4 Examples

    Example 9.4.1. Calculating work for gas processes.

    Calculate the work done on the gas for each of the three processes in Example 9.1.2 (see Figure 9.1.3).
    🔗
    Solution: Let’s deal with each of the three processes in turn:
    • Process \(1 \rightarrow 2\text{:}\) This is a constant-pressure expansion, so \(p\) can be taken out of the integral for work:
      \begin{align*} W_\text{ by } =\mathstrut \amp \int_{V_1}^{V_2}p\,dV\\ =\mathstrut \amp p\int_{V_1}^{V_2} dV\\ =\mathstrut \amp p (V_2 - V_1)\\ =\mathstrut \amp (100{kPa})(6.0{L} - 3.0{L})\\ =\mathstrut \amp 300{J}. \end{align*}
      The value of \(W_\text{ by }\) is positive, which makes sense because the gas is expanding (the volume is increasing). A short-cut to the result would be to recognize that \(W_\text{ by }\) is the area under the \(p\,-V\) curve, which in this case is a rectangle:
      \begin{equation} W_\text{ by } = (100{kPa})(6.0{L} - 3.0{L}) = 300{J}.\tag{9.4.1} \end{equation}
      The work done on the gas is \(W_\text{ on } = -W_\text{ by } = -300\) J.
      🔗
      🔗
    • Process \(2 \rightarrow 3\text{:}\) This is an isothermal compression, so \(W_\text{ on } = -W_\text{ by } = -nRT\ln (V_3/V_2)\text{.}\) We don’t know how many moles of gas there are, but we could figure it out using the Ideal Gas Law. But we aren’t going to do that, because we can replace the entire product \(nRT\) with either \(p_2V_2\) or \(p_3V_3\text{.}\) So,
      \begin{align*} W_\text{ on } =\mathstrut \amp -p_2V_2\, \ln\left(\frac{V_3}{V_2}\right)\\ =\mathstrut \amp -(100 {kPa})(6.0 L)\,\ln \left(\frac{3.0 L}{6.0 L}\right)\\ =\mathstrut \amp 416 {J}. \end{align*}
      Note that this is a positive number, which makes sense since it is a compression, and we know that \(W_\text{ on }\) is positive for a compression. Note also that the work for the process \(2 \rightarrow 3\) has a larger magnitude than that for process \(1 \rightarrow 2\text{,}\) which also makes sense because there is a larger area under the curve \(2 \rightarrow 3\) than under the curve \(1 \rightarrow 2\text{.}\)
      🔗
      🔗
    • Process \(3 \rightarrow 4\text{:}\) This is a constant-volume process, so \(W_\text{ on } = 0\text{.}\) This is also consistent with work as area under the curve, as the area under the curve for the process \(3 \rightarrow 4\) is zero.
      🔗
      🔗
    🔗
    🔗

    Example 9.4.2. Adiabatic compression.

    A diatomic gas in a well-insulated container has an initial pressure, temperature, and volume of \(150{kPa}\text{,}\) \(300{K}\text{,}\) and \(3.5{L}\text{.}\) The gas is compressed to a volume of \(0.5{L}\text{.}\) Calculate the pressure and temperature of the gas after the compression.
    🔗
    Solution: Since the container is insulated, \(Q_\text{ in } =0\text{,}\) and this is an adiabatic process. And since the gas is composed of diatomic molecules at a temperature that isn’t too high, there are 5 degrees of freedom for the gas and \(\gamma = \frac{f+2}{f} = \frac{7}{5}\text{.}\) Since this is an adiabatic process, \(pV^{\gamma} = (\text{ constant } )\text{,}\) so so \(p_iV_i^\gamma = p_fV_f^\gamma\text{,}\) which implies
    \begin{align*} p_f =\mathstrut \amp p_i\left(\frac{V_i}{V_f}\right)^\gamma\\ =\mathstrut \amp 150 {kPa}\left(\frac{3.5 {L}}{0.5 {L}}\right)^{7/5}\\ =\mathstrut \amp 2290{kPa}. \end{align*}
    🔗
    To determine the temperature after the compression, remember that in any adiabatic process \(TV^{\gamma - 1} = \text{ constant }\text{,}\) so
    \begin{equation} T_iV_i^{\gamma - 1} = T_fV_f^{\gamma - 1},\tag{9.4.2} \end{equation}
    which implies that
    \begin{align*} T_f =\mathstrut \amp T_i\left(\frac{V_i}{V_f}\right)^{\gamma - 1}\\ =\mathstrut \amp (300 {K})\left(\frac{3.5 {L}}{0.5 {L}} \right)^{\frac{7}{5}-1}\\ =\mathstrut \amp 653 {K}. \end{align*}
    🔗
    Note that the gas heats up, which is characteristic of any adiabatic compression.
    🔗
    🔗

    Example 9.4.3. A complete cycle.

    Consider a fixed amount of an ideal gas of diatomic molecules undergoing the processes shown in Figure 9.4.4. The gas starts at point A in the diagram and expands along the path \(\textbf{A}\longrightarrow{B}\) with no heat flowing into or out of the gas.
    🔗
    (a) Calculate the pressure of the gas at point B after the expansion. (b) Determine the net work done on the gas and the heat flow \(Q_\text{ in }\) in one complete cycle (\(\textbf{A}\longrightarrow{B}\longrightarrow{C}\longrightarrow{A}\)).
    🔗
    Solution: (a) Since the process \(\textbf{A} \rightarrow \textbf{B}\) is adiabatic, \(pV^\gamma = (\text{ constant } )\) and \(p_AV_A^\gamma = p_BV_B^\gamma\) so
    \begin{equation} p_B = p_A\left(\frac{V_A}{V_B}\right)^{7/5} = 100 {kPa} \times \left(\frac{1.0 {L}}{2.5 {L}}\right)^{7/5} = 27.7 {kPa}.\tag{9.4.3} \end{equation}
    🔗
    (b) We will calculate the work done on the gas for each of the three processes and add up the results to get the net work. To figure out the total heat flow \(Q_\text{ in }\) we could do something similar — i.e., calculate \(Q_\text{ in }\) for each process and then add them up. But there is an easier way: since we know that \(\Delta E_\text{ therm } = 0\) for the complete cycle, once we have determined the total \(W_\text{ on }\) for the complete cycle, we can use the First Law of Thermodynamics to get \(Q_\text{ in }\) for the complete cycle.
    🔗
    Let’s start with process \(\textbf{A} \rightarrow {B}\text{.}\) This is an adiabatic process, so \(Q_\text{ in } = 0\text{.}\) Calculating work is tricky for adiabatic processes, so we’ll find \(\Delta E_\text{ therm }\) first and then use the First Law to get \(W_\text{ on }\text{.}\) This is a diatomic gas, so \(f = 5\) and \(\Delta E_\text{ therm } = \frac{f}{2}nR\Delta T\text{.}\) \(\Delta E_\text{ therm }\) can be found with the pressures and volumes given (see (9.2.3)):
    \begin{align*} \Delta E_\text{ therm } =\mathstrut \amp \frac{f}{2}(p_BV_B - p_AV_A)\\ =\mathstrut \amp \frac{5}{2} \left(27.7 {kPa} \times 2.5 {L} - 100 {kPa}\times 1.0 {L}\right)\\ =\mathstrut \amp -76.7 {J}. \end{align*}
    🔗
    We can now find the work done on the gas via the First Law:
    \begin{align*} W_\text{ on } =\mathstrut \amp \Delta E_\text{ therm } - Q_\text{ in }\\ =\mathstrut \amp -76.7 {J} - 0\\ =\mathstrut \amp -76.7 {J}. \end{align*}
    🔗
    Process \(\textbf{B} \rightarrow \textbf{C}\) is a constant-volume process (isochoric), so \(W_\text{ on } = 0\text{.}\)
    🔗
    Process \(\textbf{C} \rightarrow {A}\) is a constant-pressure process (isobaric), so
    \begin{align*} W_\text{ on } =\mathstrut \amp -p\,\Delta V\\ =\mathstrut \amp -p\, (V_A - V_C)\\ =\mathstrut \amp -100 {kPa}\, (1.0 {L} - 2.5 {L})\\ =\mathstrut \amp 150 {J}. \end{align*}
    🔗
    So, the net work \(W_\text{ on }\) done on the gas for the complete cycle \(\textbf{A} \rightarrow \textbf{B} \rightarrow \textbf{C} \rightarrow \textbf{A}\) is
    \begin{align*} W_\text{ on } ^\text{ net } =\mathstrut \amp W_\text{ on } ^{A\to B}+W_\text{ on } ^{B\to C}+W_\text{ on } ^{C\to A}\\ =\mathstrut \amp -76.7 {J} + 0 + 150 {J}\\ =\mathstrut \amp 73.3 {J}. \end{align*}
    🔗
    As for the total heat flow \(Q_\text{ in }\) for the entire cycle, we can use the First Law:
    \begin{align*} Q_\text{ in } =\mathstrut \amp \Delta E_\text{ therm } - W_\text{ on }\\ =\mathstrut \amp 0 - 73.3 {J}\\ =\mathstrut \amp -73.3 {J}. \end{align*}
    🔗
    This means the net heat flow during the entire cycle is \(73.3{J}\) flowing out of the gas.
